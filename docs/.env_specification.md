# Environment Configuration

Copy the root `.env.example` to `.env` and replace the local database credentials. Do not commit `.env` or paste provider keys into the frontend or database.

| Variable | Required | Default | Purpose |
|---|---:|---|---|
| `DATABASE_URL` | Yes for runtime | `postgresql+psycopg://...` | PostgreSQL SQLAlchemy connection string. |
| `OPENAI_API_KEY` | For generation | Empty | Server-side OpenAI credential. Never persisted in PostgreSQL or returned by an API. |
| `OPENAI_MODEL` | No | `gpt-5` | Default text model when the AI settings row is first created. |
| `OPENAI_IMAGE_MODEL` | No | `gpt-image-1` | Default image model when the AI settings row is first created. |
| `OPENAI_SPEECH_MODEL` | No | `gpt-4o-mini-tts` | Phase 3 speech model, read on the backend at generation time. |
| `OPENAI_SPEECH_VOICE` | No | `alloy` | Standard synthetic voice; no voice cloning. |
| `OPENAI_TRANSCRIPTION_MODEL` | No | `whisper-1` | Provider transcription of uploaded audio; requires separate estimate approval. |
| `ESTIMATED_TRANSCRIPTION_USD_PER_MINUTE` | No | `0.006` | Planning-only uploaded-audio transcription rate; check current provider pricing. |
| `AI_PROVIDER` | No | `openai` | Default provider on initial configuration. |
| `DEFAULT_MAX_PROJECT_BUDGET` | No | `5.00` | Initial default project budget. |
| `DEFAULT_MAX_WAIT_MINUTES` | No | `20` | Initial default project wait time. |
| `ESTIMATED_TEXT_USD_PER_1K_TOKENS` | No | `0.002` | Planning-only text cost rate used by the estimator. |
| `ESTIMATED_IMAGE_USD_PER_IMAGE` | No | `0.04` | Planning-only image cost estimate. |
| `ESTIMATED_SPEECH_USD_PER_1K_CHARACTERS` | No | `0.015` | Planning-only speech cost rate. Review against your selected model's current pricing. |
| `STUDIO_FRONTEND_ORIGINS` | No | Localhost ports 3000 | Comma-separated CORS/mutation origins. |
| `APP_ENV` | No | `development` | Deployment environment label. |
| `LOCAL_ANIMATION_LICENSE_ACCEPTED` | For local animation | Empty (disabled) | Set to `non-commercial` only after personally accepting applicable model terms for authorized non-commercial use. |
| `LOCAL_ANIMATION_PYTHON` | No | Isolated worker Python 3.12 | Optional absolute path to the CUDA worker interpreter; never changes the web application's interpreter. |
| `LOCAL_ANIMATION_MODEL_DIR` | No | `workers/local_animation/model` | Optional local directory of the pinned FP16 SVD components. No runtime download. |

The default budget/wait and provider/model values seed the persisted `ai_configuration` singleton once. Update future defaults and model selection through `/settings/ai`. The API key remains exclusively in the server environment. Cost rates must be reviewed against current provider pricing; estimates are not provider quotes.

FFmpeg uses the existing bundled `imageio-ffmpeg` binary or `IMAGEIO_FFMPEG_EXE` pointing to an existing executable. The extension adds local document parsers; CUDA/model dependencies remain isolated from the web application. See [local deployment](./13_local_animation_extension.md). `STUDIO_TEST_POSTGRES=1` enables the optional isolated-schema production integration test; it is not a runtime setting.
